# FEATERA v11.21

延續 v11.20 的行事曆與音控排班，新增「櫃台回報」。從登入畫面進入，也可由管理員行事曆頂端開啟。櫃台與管理員可新增回報、查詢並匯出 Excel。

- 每堂課單獨填報。上課日期和課程名稱相同的多堂課也可分筆儲存。
- 課程下拉清單使用行事曆的內建類型、已儲存課程清單與既有行程。新增的課程需先由管理員同步至雲端。
- 人數及 N1～N5、S1～S3 使用非負整數。未使用的產品保留預填的 0。備註最多 2000 字元。
- 日期、月份、課程條件可一起使用。匯出工作簿包含篩選後的回報明細，以及依日期、課程、月份統計三張工作表。

## GitHub 與 Railway 部署

1. 解壓縮，將所有檔案（含 `.gitignore`、`package-lock.json`）放到 GitHub repository 根目錄並提交。附件的既有種子資料包含人員資料，建議選用私人 repository。
2. 既有 Railway 服務請沿用同一個 PostgreSQL 服務與 `DATABASE_URL`。新部署在 Railway 連接該 GitHub repository、加入 PostgreSQL，再於應用程式服務設定以下 Variables。
3. Railway 使用 `npm start` 啟動。如果已自訂 Start Command，請確認它仍然啟動 `node server.js`。Healthcheck Path 可設為 `/api/health`。
4. 部署啟動時會自動建立 `featera_course_reports` 資料表及日期索引，沿用原有行事曆與音控資料表。連線帳號須有權建立資料表與索引。
5. 上線後進入「櫃台回報」，填一筆實際課程回報，再確認查詢與 Excel 匯出。亦可分別以管理員、音控和訪客驗證原本的入口。

| Railway Variables | 用途 |
| --- | --- |
| `DATABASE_URL` | 沿用既有 PostgreSQL 連線。若服務名為 Postgres，可填 `${{Postgres.DATABASE_URL}}`。 |
| `ADMIN_USER`、`ADMIN_PASSWORD` | 沿用現有管理員帳密。未設帳號時使用 `Featera`，密碼需要設定。 |
| `DJ_USER`、`DJ_PASSWORD` | 沿用現有音控帳密。未設帳號時使用 `featera_dj`，密碼需要設定。 |
| `FRONTDESK_USER`、`FRONTDESK_PASSWORD` | 設定新版櫃台帳密以啟用櫃台登入。帳號須與管理員、音控帳號不同。 |
| `SESSION_SECRET` | 沿用既有值。新服務請設為隨機密鑰。 |

本版移除舊版公開的預填密碼及通用預設密碼。原先依賴預設密碼的服務，請在部署前設定對應密碼。帳密請在 Railway 設定。

[Railway GitHub 部署](https://docs.railway.com/quick-start) · [Railway PostgreSQL](https://docs.railway.com/databases/postgresql)

## 舊版更新紀錄

### FEATERA Calendar v11.5

本版新增：跨月空白格可雙擊輸入注意事項並同步雲端；同一行可拆成多個文字片段，每個片段可獨立設定顏色、粗體、斜體、底線；主行事曆與音控顯示均支援分段文字。舊資料相容，不需重建 PostgreSQL。

### FEATERA 行事曆排程系統 v9.0

Railway + PostgreSQL 雲端版。v9.0 新增「音控排程專區」，與講師/主持人完全分開，並使用獨立音控權限。

## v9.0 音控功能

- 獨立音控登入與權限。
- 音控帳號只能更新 `/api/audio-state`，不能寫入主行事曆 `/api/state`。
- 音控名單可新增、刪除、依地區分類，一人可支援多區。
- 音控排程與主行事曆共用同一 Railway PostgreSQL 資料庫，但以獨立資料列保存，避免互相覆蓋。
- 排程前自動檢查「音控不可與當日同區主持人為同一人」。
- 音控表的標題、欄位文字、星期名稱、主要配色均可設定。
- 每一筆音控文字可手動改字、字級、顏色、左/中/右、粗體、斜體、底線。
- 可匯出 PNG；支援 Web Share 的手機/瀏覽器可直接分享到通訊軟體或 Email，否則下載 PNG。
- 2026/09 預載畫面中的音控名單與範例排程，之後可完全自行修改。

## v10.0 台灣國定假日
- 依行政院人事行政總處辦公日曆表內建 2026、2027 國定假日、補假與連假。
- 系統假日於畫面與 PNG 匯出自動顯示，不覆蓋手動假日。
- 可於「系統設定」開關自動假日；顏色沿用「星期 / 日期配色」的國定假日顏色。
- 音控擔任表同步顯示系統假日。


## v11.0 行程編輯優化
- 上方排程欄位改為可選擇也可直接輸入新增，不再鎖定下方顯示文字。
- 新增課程/活動名稱欄位；講師與主持人可從名單帶入或直接輸入新成員。
- 可個別或一次把課程/區域、主持人、講師、統計人數「加入下方」；只追加、不覆蓋既有文字。
- 下方每行皆可自由修改文字、大小、顏色、對齊、粗體、斜體、底線及上下排序。
- 新增「儲存＋同日新增另一區」，方便同一天安排兩個以上區域課程。


## v11.1 空白行保留
- 「＋手動新增一行」即使文字完全空白，儲存後仍會保留該行。
- 空白行會依該行的字體大小保留對應高度，可用來做行距與版面留白。
- 空白行仍保留顏色、對齊、粗體、斜體、底線等格式資料。


## v11.3 行程編輯優化
- 修正「手動新增一行」空白內容不會新增的問題。
- 可新增真正空白間距行並保留字體大小/行高。
- 每行文字顏色改為：常用色票 → 最近使用色 → 其他顏色調色盤。
- 手動輸入的新課程名稱會自動加入課程資料庫；手動輸入的新講師/主持人也會自動加入各自名單，之後可直接選擇。


## v11.6 跨月空白格儲存修正
- 修正 `collectLines()` 被重複宣告覆寫的問題。
- 跨月空白格編輯器現在會正確從 `blankLineEditors` 收集每一行文字與格式。
- 儲存後會立即顯示在對應跨月空白格，並沿用 PostgreSQL 雲端同步。
- 同一行分段顏色、空白行、字級、對齊、粗體、斜體、底線均可正確保存。


## v11.7 底部聯絡資訊自由版面
- 聯絡資訊可自訂 1–6 列、1–20 行。
- 可分別調整列間距、行間距、同筆資訊內部間距、整體上下/左右留白與行高。
- 可新增、刪除、上下移動聯絡資訊。
- 名稱、地址、TEL、FAX 各自支援字級、常用/最近色票、任意色、靠左/置中/靠右、粗體、斜體、底線。
- 畫面與 PNG 匯出共用同一套聯絡資訊版面設定。


## v11.8 行程「全部加入下方」修正
- 修正「＋全部加入下方」按鈕沒有反應。
- 原因：`Array.forEach(appendDisplayLine)` 會把索引值當成 `appendDisplayLine()` 的第二個 `containerId` 參數，導致找不到 `lineEditors` 容器。
- 已改為 `forEach(line => appendDisplayLine(line))`，確保課程/區域、主持人、講師、統計人數都能正確加入下方顯示文字。
- 同步修正共用 `autofillEventLines()`。


## v11.9 分段文字顏色修正
- 修正「分段」模式下點擊顏色按鈕沒有反應的問題。
- 色票改為掛載在頁面最上層的全域浮動面板，不再受 Modal、行編輯器或分段容器 overflow 裁切。
- 分段文字仍保留常用色、最近使用顏色與其他顏色調色盤。
- 主行文字、分段文字與聯絡資訊的色票共用同一套穩定機制。


## v11.11 人員聘階/星級同步修正
- 修正講師/主持人名單切換頁籤後修改未保存的問題。
- 聘階與星級變更即時更新「自動顯示」。
- 儲存人員資料後，同步更新既有行事曆的主持人聘階與講師星級顯示文字。
- 儲存時直接同步 Railway PostgreSQL。


## v11.12 音控姓名同步更新
- 音控名單修改姓名並儲存上傳後，所有已排定且綁定該 personId 的音控排程會同步更新顯示姓名。
- 若音控排程顯示文字曾手動改成非姓名的自訂內容，則保留自訂文字，不強制覆寫。
- 分段文字若片段恰好為舊姓名，也會同步更新為新姓名。


## v11.14 人數統計資料庫化
- 每日排程保留「統計人數」欄位，課程結束後可依日期補登。
- 人數只儲存在行程資料庫欄位，不再顯示於行事曆與 PNG。
- 舊版本已產生的「統計人數：XX人」顯示行會自動隱藏，編輯後會清除。
- 統計分析新增每日明細、月總人數、已填場次平均、各區合計、課程合計、講師人數表現參考。
- 智慧推薦講師加入歷史已填人數的輕量輔助因子，僅作排課參考，不視為教學品質評分。


## v11.15
- 修正主持人/講師刪除後重新登入又被 reference.json 補回的問題：新增雲端同步刪除名單（tombstone）。
- 名單畫面不再顯示舊的歷史安排/來源摘要。
- 「排程資料庫 / 歷史參考」改為「排程規則 / 管理備註」，可由管理員輸入備註與自訂規則並同步至 PostgreSQL。


## v11.18 每月人數統計與 PDF 匯出
- 資料維護新增「📊 每月人數統計」。每日行程的統計人數儲存後，自動帶入當月統計表。
- 統計表依花蓮、高雄、宜蘭、嘉義、中壢、台南、台北、台中、台東與兩欄各區說明會配置，格式參考原始課程人數表。
- 統計表課程格可點回原行程編輯，資料與主行事曆共用同一筆 event。
- 主行事曆、音控排程、每月人數統計均新增 A4 橫式 PDF 匯出；PNG 功能保留。


## v11.19 每月人數統計獨立工作頁
- 每月人數統計改為獨立頁面，可由左上「回行事曆」返回。
- 星期一開始、星期日結尾；跨月格不顯示日期。
- 每個當月日期格都可開啟編輯，每一行可改文字、大小、顏色、對齊、粗體、斜體、底線與分段顏色。
- 預設內容即時由當月行事曆排程與簽到人數產生。第一次手動修改後會保存成統計頁獨立覆寫，不回寫主行事曆。
- 可單格或整月重設為最新行事曆資料。
- 每月統計頁支援 PNG 與 A4 橫式 PDF 匯出。

## v11.20 音控同日多人排程
- 同一日期可安排三位、四位或更多音控人員。
- 每位獨立一行，整週高度依內容自動增長，不再裁切第三位以後的人員。
- 保留既有音控名單、登入權限、PostgreSQL 雲端同步、PNG／PDF 匯出。
- 不需修改資料庫或清除資料。
