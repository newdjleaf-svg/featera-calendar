# FEATERA Calendar v11.5

本版新增：跨月空白格可雙擊輸入注意事項並同步雲端；同一行可拆成多個文字片段，每個片段可獨立設定顏色、粗體、斜體、底線；主行事曆與音控顯示均支援分段文字。舊資料相容，不需重建 PostgreSQL。

# FEATERA 行事曆排程系統 v9.0

Railway + PostgreSQL 雲端版。v9.0 新增「音控排程專區」，與講師/主持人完全分開，並使用獨立音控權限。

## Railway Variables

既有：
- `DATABASE_URL=${{Postgres.DATABASE_URL}}`
- `ADMIN_USER`
- `ADMIN_PASSWORD`
- `SESSION_SECRET`

音控帳號預設即可使用：
- 帳號：`featera_dj`
- 密碼：`featera168`

若要改音控帳密，可另外在 Railway Variables 設定：
- `DJ_USER`
- `DJ_PASSWORD`

## v9.0 音控功能

- 獨立音控登入與權限。
- 音控帳號只能更新 `/api/audio-state`，不能寫入主行事曆 `/api/state`。
- 音控名單可新增、刪除、依地區分類，一人可支援多區。
- 音控排程與主行事曆共用同一 Railway PostgreSQL 資料庫，但以獨立資料列保存，避免互相覆蓋。
- 排程前自動檢查「音控不可與當日同區主持人為同一人」。
- 音控表的標題、欄位文字、星期名稱、主要配色均可設定。
- 每一筆音控文字可手動改字、字級、顏色、左/中/右、粗體、斜體、底線。
- 可匯出 PNG；支援 Web Share 的手機/瀏覽器可直接分享到通訊軟體或 Email，否則下載 PNG。
- 2026/09 預載畫面中的音控名單與範例排程，之後可完全自行修改。

## v10.0 台灣國定假日
- 依行政院人事行政總處辦公日曆表內建 2026、2027 國定假日、補假與連假。
- 系統假日於畫面與 PNG 匯出自動顯示，不覆蓋手動假日。
- 可於「系統設定」開關自動假日；顏色沿用「星期 / 日期配色」的國定假日顏色。
- 音控擔任表同步顯示系統假日。


## v11.0 行程編輯優化
- 上方排程欄位改為可選擇也可直接輸入新增，不再鎖定下方顯示文字。
- 新增課程/活動名稱欄位；講師與主持人可從名單帶入或直接輸入新成員。
- 可個別或一次把課程/區域、主持人、講師、統計人數「加入下方」；只追加、不覆蓋既有文字。
- 下方每行皆可自由修改文字、大小、顏色、對齊、粗體、斜體、底線及上下排序。
- 新增「儲存＋同日新增另一區」，方便同一天安排兩個以上區域課程。


## v11.1 空白行保留
- 「＋手動新增一行」即使文字完全空白，儲存後仍會保留該行。
- 空白行會依該行的字體大小保留對應高度，可用來做行距與版面留白。
- 空白行仍保留顏色、對齊、粗體、斜體、底線等格式資料。


## v11.3 行程編輯優化
- 修正「手動新增一行」空白內容不會新增的問題。
- 可新增真正空白間距行並保留字體大小/行高。
- 每行文字顏色改為：常用色票 → 最近使用色 → 其他顏色調色盤。
- 手動輸入的新課程名稱會自動加入課程資料庫；手動輸入的新講師/主持人也會自動加入各自名單，之後可直接選擇。


## v11.6 跨月空白格儲存修正
- 修正 `collectLines()` 被重複宣告覆寫的問題。
- 跨月空白格編輯器現在會正確從 `blankLineEditors` 收集每一行文字與格式。
- 儲存後會立即顯示在對應跨月空白格，並沿用 PostgreSQL 雲端同步。
- 同一行分段顏色、空白行、字級、對齊、粗體、斜體、底線均可正確保存。


## v11.7 底部聯絡資訊自由版面
- 聯絡資訊可自訂 1–6 列、1–20 行。
- 可分別調整列間距、行間距、同筆資訊內部間距、整體上下/左右留白與行高。
- 可新增、刪除、上下移動聯絡資訊。
- 名稱、地址、TEL、FAX 各自支援字級、常用/最近色票、任意色、靠左/置中/靠右、粗體、斜體、底線。
- 畫面與 PNG 匯出共用同一套聯絡資訊版面設定。


## v11.8 行程「全部加入下方」修正
- 修正「＋全部加入下方」按鈕沒有反應。
- 原因：`Array.forEach(appendDisplayLine)` 會把索引值當成 `appendDisplayLine()` 的第二個 `containerId` 參數，導致找不到 `lineEditors` 容器。
- 已改為 `forEach(line => appendDisplayLine(line))`，確保課程/區域、主持人、講師、統計人數都能正確加入下方顯示文字。
- 同步修正共用 `autofillEventLines()`。


## v11.9 分段文字顏色修正
- 修正「分段」模式下點擊顏色按鈕沒有反應的問題。
- 色票改為掛載在頁面最上層的全域浮動面板，不再受 Modal、行編輯器或分段容器 overflow 裁切。
- 分段文字仍保留常用色、最近使用顏色與其他顏色調色盤。
- 主行文字、分段文字與聯絡資訊的色票共用同一套穩定機制。


## v11.11 人員聘階/星級同步修正
- 修正講師/主持人名單切換頁籤後修改未保存的問題。
- 聘階與星級變更即時更新「自動顯示」。
- 儲存人員資料後，同步更新既有行事曆的主持人聘階與講師星級顯示文字。
- 儲存時直接同步 Railway PostgreSQL。
